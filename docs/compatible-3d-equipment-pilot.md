# Nymeria — compatible 3D equipment pilot (research checkpoint)

**Status:** asset pack identified; no 3D outfit imported or visually tested yet. This is not an art approval.

## Candidate: Quaternius modular ecosystem

- Universal Base Characters: https://quaternius.itch.io/universal-base-characters
- Modular Character Outfits — Fantasy: https://quaternius.itch.io/modular-character-outfits-fantasy
- Free Standard downloads currently listed at 122 MB (base) and 280 MB (outfits).
- Fantasy pack lists 12 outfits, 62 separate parts, 3 texture variations per outfit, humanoid rig, and compatibility with Universal Base Character heads.
- License indicated on both pack pages: CC0 1.0; confirm inside ZIP before shipping.
- Quaternius changelog v2.0 notes improved modularity / fewer clipping problems; this is not a guarantee of zero clipping.
- Source editions are paid; pilot must use free Standard editions only.

## Reproducible pilot acceptance

1. Acquire Standard archives from publisher, retain original archive names and license.
2. Extract one compatible base and two different outfit components, retaining glTF textures and BIN references.
3. Inspect bone names and skin bindings, verify same skeleton/reference pose.
4. Render three states from one fixed camera: base, outfit A, outfit B.
5. Verify no unacceptable intersections at shoulders, waist, legs, hands in all three states.
6. Export transparent 2D portraits at identical resolution and compare visual quality on iPhone.
7. Only if approved, prototype equipment toggles in an isolated DEV page; no gameplay integration.

## Current blocker

The publisher serves the free Standard archives through itch.io's interactive download flow. No authenticated download or complete archive acquisition has been performed in this checkpoint. Do not substitute unrelated GLB models and claim that equipment compatibility was tested.
